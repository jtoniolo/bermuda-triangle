# Triage labels

The skills use five canonical triage roles. This file maps each role to the label string in the issue tracker for this repo.

| Role in mattpocock/skills | Label in this tracker | Meaning                                               |
| ------------------------- | --------------------- | ----------------------------------------------------- |
| `needs-triage`            | `needs-triage`        | A maintainer must examine this issue.                 |
| `needs-info`              | `needs-info`          | The reporter must supply more information.            |
| `ready-for-agent`         | `ready-for-agent`     | The issue is fully specified. An agent can do it.     |
| `ready-for-human`         | `ready-for-human`     | A human must do this issue.                           |
| `wontfix`                 | `wontfix`             | Nobody will do this issue.                            |

When a skill names a role, use the label string from this table.

To use different label strings, change the second column.
